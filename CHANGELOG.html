代码与日志对齐规则

任何影响仓库内容或系统行为的修改，必须在同一个提交或变更集中更新本文件。未记录、记录与实现不一致、或缺少验证证据的修改，均视为未完成，不得交付或合并。

同步发生

证据闭环

2026-09-06
Unreleased

完成 Epic 2 E2.1 本地实现：将冻结 Agent Payment API v1 包装为 Monorepo 内部 TypeScript SDK，使外部 Agent 获得生成类型、显式幂等和可执行的失败恢复语义，而不复制 Transaction Core 或自动重试未知资金结果。

Changes

  • Added新增私有包 @bu2/sdk v0.1.0，覆盖 Quote、PaymentIntent、Authorization、Transaction、DeliveryEvidence、Settlement、Recovery 和 Receipt。
  • Added使用 openapi-typescript 7.13.0 从冻结 OpenAPI 生成请求与响应类型，并加入生成漂移门禁；运行时复用 openapi-fetch 0.17.0。
  • Changed所有写操作要求调用方提供显式幂等键；SDK 不自动重试，写入超时、网络失败或 5xx 返回 query_before_retry。
  • Added稳定 SDK Error 保留 HTTP status、BU2 type/code、request/trace ID、details 与恢复分类；中英文文档明确 Simulation/Testnet 和未公开发布边界。

Webhook 可靠性闭环 E1.1

2026-09-05
Unreleased

完成 Epic E1.1：Reference Sandbox v0.5 将 Webhook 从无限重试原型升级为可恢复、可审计且支持 Secret 版本轮换的可靠投递闭环。

Changes

  • Added新增事务化 Worker 租约、有限指数退避、退避上限与 jitter；并发 Dispatcher 只领取一次，进程重启后可回收过期租约。
  • Added达到最大尝试次数后进入确定的 dead_letter；公开死信与逐次投递审计查询。
  • Added新增幂等人工重放，保留原 event_id 和载荷，记录操作者、理由与 replay cycle，不新增 LedgerEvent。
  • Added新增版本化 Webhook Secret 与有限重叠轮换；重叠期携带新旧 HMAC，所有公开响应和审计记录不返回明文 Secret。
  • ChangedSQLite 使用 additive migration 新增投递审计、重放、Secret 版本和轮换表，并兼容迁移 v0.2 订阅与 Outbox 数据。
  • ChangedOpenAPI、HTTP 运行时、Sandbox README 和技术基线同步升级到 Reference Sandbox 0.5.0。
