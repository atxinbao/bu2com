# BU2 Transaction-first P0 验收方案

日期：2026-09-01  
执行者：Codex

## 主路径

1. 默认进入 Transactions，不能出现创建 Task 的要求。
2. 打开 `PAY-8421`，确认 payer、payee、buyer agent、seller agent、商品、金额和外部上下文完整。
3. 查看首次商户需要确认的 Payment Mandate 原因。
4. 点击授权付款后，状态变为“资金已预留”，待授权数量从 1 变为 0。
5. 此时 Receipt 尚未生成，交易不得显示已结算。
6. 点击确认交付并结算，状态变为“已结算”。
7. 时间线出现交付证据、结算事件和 Receipt ID。
8. 返回 Transactions，`PAY-8421` 状态同步为已结算。

## 辅助路径

- Authorizations 在授权前显示 1，授权后显示空队列。
- 已结算交易能查看完整交易详情，不误关联到 `PAY-8421`。
- 中文界面不出现不必要的英文 UI；英文界面除语言按钮“中文”外无中文残留。
- 浏览器控制台无错误。

## 结论规则

- GO：主路径 8 项全部通过，且授权、预留、交付、结算没有状态混淆。
- ITERATE：闭环可完成但存在信息或同步问题。
- STOP：仍要求用户创建任务，或无法区分授权、预留与结算。
